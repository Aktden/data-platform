## Разбор восьми разделов

| Раздел | Операторы и действия |
|---|---|
| 1 Требования вакансии | Переменные `NAVYKI`, `GOROD`, `POTOLOK`, `OPYT_MESYACEV` |
| 2 Каждое требование | `$all`, `$or`, `$lte`, `$elemMatch` с `$gte`, `$exists`, `count_documents()` |
| 3 Все требования сразу | Совместный фильтр, `find()`, сортировка по `salary`, `count_documents()` |
| 4 Должности Junior | `$regex: "^junior"`, `$options: "i"`, проекция полей |
| 5 Подходящие вакансии | `salary.from <= 90000` и `salary.to >= 90000` через `$lte`, `$gte` |
| 6 Собеседования за неделю | Диапазон дат `$gte` и `$lt`, точные условия на `stage` и `format` |
| 7 Качество данных | `$exists`, `$not`, `$type`, `$size`, `$expr`, `$gt`, `$ne` |
| 8 Причины отказа | Чтение документов и проверки навыков, зарплаты, города и опыта в Python |

Признак наличия контактов проверяется в разделе 2, но в совокупный фильтр раздела 3 не включён. Поэтому его не следует добавлять к исходным четырём требованиям при сравнении экспериментов.

## Исходный запуск

```bash
python lesson_05/hh_search.py
```

Исходные требования: Python и SQL, Ярославль или готовность к переезду, зарплата не больше 100000, хотя бы одно место работы от 6 месяцев. Из 9 резюме навыки проходят у 4, город — у 8, зарплата — у 5, опыт — у 6, контакты есть у 8. Всем четырём требованиям соответствует Пётр Ковалёв с ожиданиями 70000.

## Вывод

Нужно повысить только потолок зарплаты со 100000 до **120000**. Тогда проходят три кандидата: Пётр Ковалёв — 70000, Ольга Пирогова — 110000, Алина Дроздова — 120000. В разделе 8 Алина и Ольга отклонены только из-за зарплаты, поэтому остальные требования менять не требуется. При 110000 проходят только двое; 120000 — минимальный достаточный потолок на этих исходных данных.

После проверки своё тестовое резюме удалено; в исходной коллекции снова 9 документов. При ручном выполнении задания учебные данные можно восстановить командой `python scripts/load_course.py --reset` из корня проекта либо штатным загрузчиком стенда.
