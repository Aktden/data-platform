# Решение задания 5

Скрипт `hh_search.py` из практик преподавателя использует:

1. `$all` — оба требуемых навыка;
2. `$or` — нужный город или готовность к переезду;
3. `$lte` — потолок зарплаты;
4. `$elemMatch` — опыт работы нужной длительности;
5. `$regex` — должности, начинающиеся с `Junior`;
6. два условия по `salary.from` и `salary.to` — попадание ожидания в вилку;
7. `$exists`, `$not` + `$type`, `$size`, `skills.0` и `$expr` — контроль качества данных;
8. программные сравнения — причины, по которым кандидат не прошёл.

Заполните числа после запуска и добавьте своё резюме через Compass. После проверки восстановите стенд командой `docker compose run --rm reset`.
