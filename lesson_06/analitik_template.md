Ниже оставлен каркас. После прохождения практикума скачайте официальный файл рецензии и замените этот файл им.

## Правильные идеи для ответов

- Ревью запросов: проверять имена полей, типы значений, оператор `$or` для альтернатив и `$elemMatch` для условий внутри одного элемента массива.
- Сборка запросов: фильтр, проекция и сортировка задаются отдельно, затем объединяются в один вызов `find`.
- «Сито»: сначала серверные фильтры, затем программная классификация причин отказа.
- Свои запросы: обязательно указать коллекцию, фильтр, ожидаемое число и фактический результат.

Официальные баллы и тексты рецензии: вставить из скачанного `analitik_<фамилия>.md`.
