## Содержание

Модуль 2 справочника посвящён фильтрам. Фильтр — это документ: поля
и условия на их значения.

| Глава | Операторы | Что проверяют |
|---|---|---|
| 2.1 | точечная нотация `"address.city"` | поле внутри вложенного объекта |
| 2.2 | `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte` | сравнение |
| 2.3 | `$in`, `$nin` | значение есть или нет в списке |
| 2.4 | `$and`, `$or`, `$not`, `$nor` | логика условий |
| 2.5 | `$exists`, `$type` | есть ли поле и какого оно типа |
| 2.6 | `$all`, `$elemMatch`, `$size` | условия по массиву |
| 2.7 | `$regex`, `$options` | текстовый шаблон |
| 2.8 | `$expr` | сравнение полей одного документа между собой |

### Скрипт подбора кандидатов (глава 2.9)

Скрипт `hh_search` собирает операторы модуля 2 в рабочий отбор по базе `hh`.
Требования к кандидату — навыки, город, потолок зарплаты, срок работы —
лежат в переменных в начале файла, из них собираются фильтры.

1. Сначала по одному требованию: счётчик показывает, какое требование
   отсекает кандидатов.
2. Затем все требования сразу: пары фильтра соединяются через «и», `$or` —
   одна из пар.
3. Поиск по части строки и подбор вакансий по вилке зарплаты.
4. Период дат полуинтервалом: `$gte` начало, `$lt` следующий день.
5. Проверка данных: `$exists`, `$type`, `$size`, `$expr`; ноль найденных —
   дефектов нет.

Причину отказа кандидату считает программа: фильтр её не возвращает.
Отбор при этом остаётся на сервере.
