## Содержание лекции

### Документ

Одна анкета соискателя в PostgreSQL занимает шесть таблиц, в MongoDB —
один **документ** на 697 байт. Документ — это то, что кладут и достают
целиком: он читается и меняется одной операцией. Поэтому у документов одной
коллекции может быть разная форма, а условие по массиву пишется без индекса
элемента.

| Понятие | Что это |
|---|---|
| сервер | процесс MongoDB, к которому подключается клиент |
| база | набор коллекций |
| коллекция | набор документов, схема заранее не задаётся |
| документ | запись из полей и значений, в том числе вложенных объектов и массивов |

### BSON и _id

MongoDB хранит документы в формате **BSON** — двоичном представлении
с типами. Документ `{ n: "Пётр" }` занимает 21 байт. У каждого документа
есть поле `_id`; если его не задать, сервер создаёт **ObjectId** из 12 байт,
первые четыре — время создания. Индекс по `_id` в коллекции один и создаётся
автоматически.

### Compass

**MongoDB Compass** — графический клиент. Строка подключения к стенду:
`mongodb://localhost:27017`. В Compass создают базу и коллекцию, вставляют
документ и загружают набор данных через **ADD DATA**.

### Фильтры

| Фильтр | Найдено | Что проверяет |
|---|---|---|
| `{ city: "Ярославль" }` | 5 из 9 | точное совпадение строки; регистр и пробелы меняют значение |
| `{ "education.level": "СПО" }` | 4 из 9 | поле внутри вложенного объекта через точку |
| `{ skills: "MongoDB" }` | 2 из 9 | условие проверяется для каждого элемента массива |
| `{ salary: { $gt: 100000 } }` | 4 из 9 | сравнение чисел; строка `"120000"` не найдётся |
| `{ portfolio: { $exists: true } }` | 2 из 9 | наличие поля |
| `{ city: Ярославль }` | ошибка | строка без кавычек: фильтр не разобран, запрос не ушёл на сервер |

Неверно записанный фильтр даёт **ошибку разбора**, а верный фильтр без
совпадений — **пустой результат**. Это разные ситуации.

Ошибки подключения: `ECONNREFUSED 127.0.0.1:27017` — сервер не запущен,
`Server selection timed out` — адрес недоступен.
