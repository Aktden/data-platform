# Рецензия по практикуму «Инженер платформы»

Фамилия, имя: ____________________  Группа: __________  Дата: __________

## Правильные ответы

- Для равенства по одному полю — одиночный индекс.
- Для фильтров `service`, `level`, сортировки `ts` и диапазона `duration_ms` — `{ service: 1, level: 1, ts: -1, duration_ms: 1 }` по правилу ESR.
- В плане до индекса: `COLLSCAN → SORT`, после индекса: `IXSCAN → FETCH`; `nReturned` остаётся 33, `totalDocsExamined` уменьшается с 1200 до 33.
- Размер индекса на 1 000 000 событий нужно брать из фактического `collStats`/практикума.
- При ревизии удалить лишние и дублирующие индексы, оставить только те, которые поддерживают реальные запросы; `_id_` не удалять.

Официальные баллы и планы вставьте из скачанного файла практикума.
