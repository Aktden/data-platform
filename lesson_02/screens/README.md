## Выводы по модулю 1

MongoDB хранит данные в документах BSON, документы объединены в коллекции и базы. Вложенные объекты позволяют хранить связанные поля вместе, массивы - несколько значений одного признака. Поля цены и количества следует хранить числами, а даты, участвующие в диапазонах времени, - типом Date. У каждого документа есть уникальное поле `_id`; остальные поля могут отличаться между документами одной коллекции.

Пустой фильтр `{}` читает все документы, а условие по полю ограничивает результат. Для вложенного поля используется точечная нотация; равенство скалярному значению для массива проверяет наличие элемента. Compass позволяет импортировать JSON и проверять документы и их количество. Импорт и повторный запуск проверяются по самой коллекции, а не только по сообщению об успешном выполнении команды.
