# Материалы занятий

Файлы и ссылки на материалы занятий, по одной папке на занятие. Конспекты
лежат в папке [`lectures`](../lectures/README.md).

[mongodb-practice](https://github.com/MaximBytecamp/mongodb-practice): в нём стенд
с базами курса и файлы заданий. Здесь лежат ссылки на нужные папки.
