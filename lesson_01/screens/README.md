## 1. Описание коллекции

Предметная область - **обращения пользователей в техническую поддержку**.

В базе данных `training` создана коллекция `tickets`, содержащая пять документов. Каждый документ представляет отдельное обращение пользователя и включает сведения о теме, состоянии, приоритете и клиенте.

### Структура документа

| Поле | Тип данных | Назначение |
|:---|:---|:---|
| `_id` | Строка | Уникальный идентификатор тикета |
| `title` | Строка | Тема обращения |
| `status` | Строка | Текущее состояние обращения |
| `priority` | Число | Приоритет обращения |
| `customer` | Объект | Данные клиента: имя и город |
| `tags` | Массив строк | Теги обращения |
| `assignee` | Строка | Ответственный сотрудник |
| `resolved_at` | Дата или строка | Время закрытия обращения |
| `channel` | Строка | Канал поступления обращения |

Поля `assignee`, `resolved_at` и `channel` являются необязательными. Поэтому документы могут иметь разную структуру.

Например:
- В документе `t-004` присутствует поле `resolved_at`, но отсутствует `assignee`.
- В документе `t-005` присутствует поле `channel`, но отсутствуют `assignee` и `resolved_at`.

### Импорт данных

Готовые документы находятся в файле [`seed.json`](seed.json). Файл содержит корректный JSON-массив, который можно импортировать в MongoDB Compass.

Порядок импорта:

1. Открыть базу данных `training`.
2. Выбрать коллекцию `tickets`.
3. Нажать **ADD DATA → Import JSON or CSV file**.
4. Выбрать файл `seed.json`.
5. Выполнить импорт данных.

**Фильтр:**

**Результат:** 2 документа - `t-002`, `t-005`.

### Запрос № 5. Проверка существования поля

**Фильтр:**

`{ resolved_at: { $exists: true } }`

**Результат:** 1 документ - `t-004`.

Оператор `$exists: true` проверяет наличие поля `resolved_at` в документе. Значение поля при этом не обязано быть непустым.

### Запрос № 6. Синтаксическая ошибка

**Некорректный фильтр:**

`{ status: "открыт"`

**Результат:** ошибка разбора запроса.

В фильтре отсутствует закрывающая фигурная скобка `}`. Поэтому MongoDB Compass не может корректно разобрать выражение, выделяет поле фильтра красным цветом и делает кнопку **Find** недоступной.

Документ, который остаётся на экране после ввода некорректного фильтра, относится к предыдущему успешно выполненному запросу. Он не является результатом выполнения ошибочного фильтра.
